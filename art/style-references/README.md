2026-10-21. Every art task renders to match them.

## Look

- Painterly, sunlit post-apocalyptic salvage town with neon signs.
- Rusted metal, painted scrap, duct tape and patches, neon accents.
- Display type is bold, hand-painted and rough. Body type is clean and readable.
- The crown tag is the recurring mark. Spark is the robot companion.

The sheets contain lettering. Generated game art does not: UI text stays in HTML.
